# 现阶段波动率大小衡量方法

- [x] 目前只对加密数字货币 `BTC-USD`/`ETH-USD` 进行了计算分析


## 波动大小计算准备

- 1、取出要分析的数据，根据时间维度取出最新的一段时间的数据，默认取 `20分` 钟的数据，计算频率默认为 `一分钟` 一次
- 2、分析该时间段类所有的 `CClose` 字段
- 3、统计所有的数据点，总共多少个
- 4、取出该段数据的初始值、结束值
- 5、从初始值开始，第 （`n`） 个值与（`n+1`）一个值进行对比，同时判断是否涨跌，记录中间的涨/跌( `UpCount` / `DownCount` )次数，连续涨跌的权重
- 6、统计上涨次数占比、下跌次数占比，平滑次数占比（平滑在这里的定义：认为 `n` 与 `n+1` 相等就算平滑）
- 7、计算平方差，平均值，方差越大波动越大，计算得到的方差进行存储，后面用来作为标准衡量

### 波动大小定义：
- 1、上涨率和下跌率决定

- [x] 根据上涨率或者下跌率占比大于 `65%` ，认定为斜线上涨或者斜线下跌，这种定义为波动小，这样的斜线认为是 `明显可预测` 的波动

- 2、根据方差大小定义波动，方差越大，波动越大，波动越大赔率越大

- [x] 方差多大为 `大` ，方差多小为 `小` ，这里方差的大小用过去 `20分钟` 的波动产生的历史方差来衡量
