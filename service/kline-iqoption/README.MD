1、针对节假日数据源推送问题，比如今天，国外的平安夜，交易市场休市了，但是普通的数据源还有数据推送，虽然时间上是在推送但是一直都是推送重复的时间点数据，没有任何的意义
针对以上问题需要检测数据源是否健康，首先收集最近的一分钟数据，将最近的一分钟数据放到redis缓存，然后我们去检测这一分钟的数据，当数据的close值是一条直线的时候，我们
就判定数据为不健康状态，将数据置为休市状态，同时数据不能入库，只能在缓存面徘徊
